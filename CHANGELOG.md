# Changelog

## [1.1.0] – 2026-10-24

First installable release for Android, Windows and Linux.

- Library for books, web novels, fanfiction, manga and comics, with searchable
  filters, categories, series, characters, tags and reading progress.
- Read online or import EPUB, FB2, TXT, HTML and CBZ files; download chapters for
  offline reading and export them in different formats.
- Estimate missing word/page counts, including Author.Today character counts and
  chapter sampling. Resume incomplete downloads and optionally leave images out.
- Custom reader width, colors and fonts; manga page layouts; bookmarks and notes.
- Reading statistics, paper-book progress, catalog/ISBN/AniList lookup, backups,
  trash, diagnostic logs and optional automatic downloads of new chapters.
- Versioned release packages and checksums built automatically by GitHub Actions.

Android currently supports HTTP sources and local files. Sources requiring the
embedded desktop browser (including Cloudflare/age-confirmation flows) are not
supported on Android yet. AI-provider integration is not part of this release.
